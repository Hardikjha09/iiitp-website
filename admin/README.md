# Admin Dashboard — React + Vite SPA

Admin-only CMS frontend for the IIIT Pune website.

## Stack
- React 19 + Vite
- Google OAuth2 login (no username/password)
- JWT cookie-based auth

## Setup
```bash
npm create vite@latest . -- --template react
npm install
npm run dev
```

See `BACKEND_IMPLEMENTATION_PLAN.md` in the root for screen-by-screen design and role access matrix.
